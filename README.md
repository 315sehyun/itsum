# 잇섬 — 덜 찬 화물, 함께 실어 제주까지

제주행 화물 공동운송 플랫폼 **잇섬**의 고객용 웹 화면입니다. 2026 물류 해커톤 출품작입니다.

## 화면

- **견적 받기** (3단계)
  1. 화물 정보 입력: 롤테이너·박스·부피, 온도, 출발지, 목적지, 출발 일시
  2. 운임 확인: 내 운임, 혼자 보낼 때 대비 절감액, 배정 배편과 결항 위험
  3. 계산 근거: 트럭 적재 그림, 운임 계산 단계, 물량별 운임, 보내는 방법 비교
- **내 예약 조회**: 예약 번호로 배편·도착 예정 확인 (이 브라우저에만 저장되는 시연용)
- **요금 안내**: 부피 비율 분담 방식, 혼자 보낼 때 비용 상한, 가정값과 출처

## 운임 계산 규칙

- 트럭 1대 = 롤테이너 12칸, 0.25칸 단위 올림 과금
- 내 운임 = 트럭 대수 × 도선료 × (내 칸 수 ÷ 전체 칸 수) + 칸당 하역비 3,000원
- 혼자 트럭을 띄울 때 비용을 넘지 않도록 상한 적용
- 도선료: 월~토 364,380원, 일·공휴일 406,410원 (목포→제주, 4.5톤 단축 적재)
- 결항 확률이 기준값(기본 50%)을 넘으면 다음 배편으로 미리 배정

예시: 평일 상온 3칸, 같은 배편 다른 고객 잔량 6칸 → 내 운임 130,460원 (혼자 364,380원, 64.2% 절감)

## 데이터

다른 고객 물량, 파고·풍속, 결항 확률은 **가상 데이터**입니다. 결항 확률은 학습된 모델이 아니라 파고·풍속으로 계산하는 예시 식입니다. 도착 시각, 화물 마감 시각, 육로 소요 시간 등은 요금 안내 화면의 가정값 표에 "가정"으로 표시했습니다.
